# Chaintech Task Manager - Backend

A simple and efficient Task Management API built with **Node.js**, **Express**, and **MongoDB Atlas**.

## 🚀 Features
- **Task Creation**: Add new tasks to the database.
- **Task Retrieval**: View all stored tasks.
- **Cloud Database**: Fully integrated with MongoDB Atlas.
- **Environment Safety**: Uses `.env` for secure credential management.

## 🛠️ Tech Stack
- **Node.js** & **Express** (Backend Framework)
- **Mongoose** (Database Modeling)
- **MongoDB Atlas** (Cloud Database)

## 📖 How to Run Locally
1. Clone this repository.
2. Run `npm install` to install dependencies.
3. Create a `.env` file and add your `MONGODB_URI`.
4. Run `node server.js` to start the server.
